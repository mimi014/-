# ユアユニ 自動動画制作アプリ

YouTube切り抜き動画を簡単に作成するためのWebアプリケーションです。

## 機能

- YouTube動画URLから動画情報を自動取得
- ビデオプレビュー機能
- 複数のクリップを簡単に選択・管理
- メタデータ入力フォーム
- ユアユニの規約チェックリスト
- JSON形式での設定出力
- ffmpeg/yt-dlpスクリプトの自動生成

## 使い方

### 1. アプリケーションを開く

ブラウザで `video-creator.html` を開きます。

```bash
# ローカルサーバーを起動する場合
python -m http.server 8000
# ブラウザで http://localhost:8000/video-creator.html を開く
```

### 2. YouTube動画を読み込む

1. YouTube動画のURLを入力欄に貼り付けます
2. 「動画を読み込む」ボタンをクリックします
3. 動画プレーヤーに動画が表示されます

### 3. クリップ範囲を選択

1. 動画を再生して、切り抜きたい部分を確認します
2. 開始位置で「現在位置を設定」ボタンをクリック（または手動で秒数を入力）
3. 終了位置で「現在位置を設定」ボタンをクリック（または手動で秒数を入力）
4. 「クリップを追加」ボタンをクリックして保存します
5. 複数のクリップを追加できます

### 4. 動画情報を入力

- **切り抜き動画のタイトル**: 公開する動画のタイトル
- **動画の説明**: 動画の内容説明（元動画URLと元チャンネル名を含める）
- **あなたのチャンネル名**: 【公認切り抜き】を含むチャンネル名
- **コメント欄**: 有効にする（必須）
- **動画カテゴリ**: 適切なカテゴリを選択

### 5. 規約を確認

すべての禁止事項を確認し、チェックボックスにチェックを入れます。

### 6. 出力を生成

- **JSON出力**: 設定をJSON形式で出力します
- **スクリプト生成**: yt-dlpとffmpegを使用したBashスクリプトを生成します

## 生成されたスクリプトの使用方法

### 必要なツール

```bash
# yt-dlp のインストール
pip install yt-dlp

# gdown のインストール（Google Driveからのダウンロード用）
pip install gdown

# ffmpeg のインストール (Ubuntu/Debian)
sudo apt-get install ffmpeg

# ffmpeg のインストール (macOS)
brew install ffmpeg
```

### スクリプトの実行

1. 生成されたスクリプトをコピーして、`create_clips.sh` として保存
2. 実行権限を付与: `chmod +x create_clips.sh`
3. スクリプトを実行: `./create_clips.sh`

スクリプトは以下の処理を行います:
- YouTube動画のダウンロード
- Google Driveからエンディング動画のダウンロード
- 指定された範囲のクリップ作成
- 各クリップの最後にエンディング動画を自動結合
- メタデータファイルの生成

## エンディング動画について

すべてのクリップには自動的にエンディング動画が追加されます。

- **エンディング動画URL**: https://drive.google.com/file/d/1cn486ZQzMqYhEA1mkw8VM8QcFf4nPJ1b/view
- 各クリップの最後に自動的に結合されます
- ffmpegのconcat demuxerを使用して無劣化結合します
- SHORTsを除くすべての動画に必須です（ユアユニの規約）

## ユアユニの規約について

### 切り抜き収益化の条件

- YouTube全収益は切抜き者が獲得
- その代わり税務条件は100%発社員履歴
- 再生100回以上の当月動画の対象者
- 動画・ブロ共に月額500円／7日800円で収益化
- 普通／プロ共に月耳計20本が上限
- プロ認定者の定義は以下3つ
  - チャンネル登録者万人以上
  - 全動画の総再生時間が全てクリア
  - ユアユニやサービス紹介者得福田担当者以上

### 動画の条件

- 竹花YouTube上にあるものは必ず機種を加える
- ユアユニブリに動画の音声動画は数対に難しい
- 動画への0いわけ数が直低10以上ること
- TikTokやSNS端にも自由に掲載可能
- 動画投稿後はTwitterにも投稿
- 5分以上の動画は基本NGだが複数の短い動画を5分ぱ以内に切抜き、各動画は最後に挿入する
- 全動画（SHORTきむ）に下記動画素材を必ず動画の最後に挿入する
- 素材ダウンロード 縦動画：[リンク] / 横動画：[リンク]

### 動画以外の条件

- チャンネル名：（【公認切り抜き】任意の名前）
  例：【公認切抜き】竹花貴騎の動画部屋
- 動画の詳細画とコメント欄に必ず以下を記載し他の文章の記載は一切禁止
  - サンプル動画（こちら）、詳細（こちら）
  - 全編はこちら：[URL]
  - 毎日のインスタで知識配信：[URL]
  - 就活はユアユニオンラインスクールで検索
  - 就活はエアユニオンラインスクールで検索

### 禁止行為やルール

- サムネや動画で他人文字や実績を認定する行為はNG
- 竹花のユアユニ限定ライブコンテンツ利用禁止（有料のため）
- エイプリルフールで出した嘘過ぎる「除籍」「許可」「違法」などの文言はNG
- 同じ文言はSEOし過ぎしまうの尾でNG
- 経緯によっては他人の動画、ブログを転載した問合はチャンネル削除申請を行います
- 無断で竹花情報を利用して著作権接を行った場合は契約経反保
- 彼ややviewの購入などをを行った場合はチャンネル削除対語
- 何他の動画・ブログを転載した商合は代理店経稿保
- 経緯によっては収益、又、他サービスの口コォ入っているものもNG

### 報酬申請の仕方

- 各条件を満たしていることを確認して報酬申請
- 担当レビュー後に、クラスタ口座登録がない場合音報酬は振込ません また理由っての個別計算と撤かも受け付けません
- 毎月月末締め、翌月5日以前申請、月末が出月間の提出期限

## 技術仕様

- **フロントエンド**: HTML5, CSS3, JavaScript (ES6+)
- **YouTube API**: YouTube IFrame Player API
- **動画処理**: yt-dlp, ffmpeg

## 注意事項

1. YouTube IFrame Player APIを使用するため、インターネット接続が必要です
2. 実際の動画ダウンロードとクリッピングには、yt-dlpとffmpegが必要です
3. YouTube Data APIを使用する場合は、APIキーの取得が必要です
4. 著作権を遵守し、ユアユニの規約に従ってください
